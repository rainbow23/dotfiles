# Memoフィルター機能 使い方

メモの先頭文字列（グループ名）で表示をフィルターする機能。
実装: `nvim/lua/rc/memo.lua`（セッション連携は `nvim/lua/rc/session.lua`）

## 概要

- メモの先頭文字列がフィルター文字列と前方一致するメモのみを表示する
- 例: フィルター `HOGE` を適用すると `HOGE AAA` `HOGE BBB` のメモだけが表示される
- 非表示メモも extmark 自体は残るため、フィルター中に行編集しても位置は正しく追従する

## キーマップ

| キー | 動作 |
|---|---|
| `<leader>mg` | フィルター決定。カーソル行にメモがあればそのテキストを初期値に編集（方式1）、なければ空入力から新規作成（方式2）。Enter で登録・適用。入力中は `<C-k>`/`<C-j>` で登録済みフィルターをポップアップから選べる |
| `<leader>mt` | フィルターごとの適用 ON/OFF と全体の ON/OFF をポップアップで切り替える |
| `<leader>mo` | Telescope フィルター一覧を表示 |

## フィルター決定のポップアップ（`<leader>mg`）

`Filter:` の入力中に `<C-k>` を押すと、コマンドラインの直上に登録済みフィルターのポップアップが出る。

| 操作 | 動作 |
|---|---|
| `<C-k>` | 1 つ上（古い方）へ移動。初回は最下行（最近使ったフィルター）を選択。ポップアップ表示中は `<C-p>` でも可 |
| `<C-j>` | 1 つ下（新しい方）へ移動。最下行で止まる。ポップアップ表示中は `<C-n>` でも可 |
| `<CR>`（ポップアップ表示中） | 確定。ポップアップを閉じ、選んだ名前を入力欄に残して編集を続ける |
| `<CR>`（ポップアップなし） | 入力内容でフィルターを登録・適用 |
| 文字入力 | ポップアップを閉じて、そのまま編集を続ける |

- 並び順は最近使った順（古いものが上、最新が最下行）。フィルターを適用（`<leader>mg` で決定、`<leader>mt` で ON）した日時で更新される
- 選択中の行で入力欄の文字列も置き換わる

## メモ追加・編集時のフィルター選択（`<leader>ma`）

`Memo:` の入力中も `<C-k>` で同じフィルターポップアップが出る。選んだフィルター名が入力中の文言の先頭に付く。

例: `AA` のメモで `<leader>ma` → `<C-k>` で `filterA` を選ぶ → 入力欄が `filterA AA` になる → `<CR>` で確定

| 操作 | 動作 |
|---|---|
| `<C-k>` / `<C-j>` | フィルターを選ぶ（操作は `<leader>mg` と同じ）。入力欄は「フィルター名 + 元の文言」に置き換わる |
| `<CR>` | ポップアップを閉じてメモを確定する（ポップアップ表示中でも 1 回で確定） |
| 文字入力 | ポップアップを閉じて編集を続ける |

- 元の文言に登録済みフィルター名が付いている場合は付け替える（例: `HOGE BB` で `FUGA` を選ぶと `FUGA BB`）
- 新規メモでは「フィルター名 + 空白」が入るので、そのまま続けて入力できる

## フィルター切り替えのポップアップ（`<leader>mt`）

```
╭─ Filter Toggle [ON]  <C-k>/<C-p>=上(古い) <C-j>/<C-n>=下(新しい) <Tab>=ON/OFF <CR>=閉じる ─╮
│ ██ FUGA                                       │
│ ██ HOGE※                                      │
│ ██ TODO※                                      │
│ ◉ 全体: ON      ← 起動直後はここ               │
╰───────────────────────────────────────────────╯
```

| 操作 | 動作 |
|---|---|
| `<C-k>` / `<C-p>` / `k` | 上へ移動 |
| `<C-j>` / `<C-n>` / `j` | 下へ移動 |
| `<Tab>`（フィルター行） | そのフィルターの適用を ON/OFF（適用中は `※`）。適用中が 0 件になると全体も OFF |
| `<Tab>`（全体の行） | フィルター適用全体の ON/OFF（従来の `<leader>mt` と同じ）。適用中フィルターが 0 件のときは切り替えない |
| `<CR>` / `<Esc>` / `q` | 閉じる（切り替えは `<Tab>` の時点で反映済み） |

- 並び順は `<leader>mg` のポップアップと同じ（最新が下）。開いている間は並びを固定する

## Telescope フィルター一覧（`<leader>mo`）

| 操作 | 動作 |
|---|---|
| `<Tab>` | カーソル行フィルターの適用/未適用を即時トグル（トグル後カーソルは1行上へ移動） |
| `<CR>` | 閉じる（適用状態は `<Tab>` で反映済み） |
| `<C-d>` | フィルター定義を削除（メモ本体は変更しない） |

- 各フィルターは色アイコン `██` 付きで表示される（グループ色未設定はデフォルトのメモ色）
- 適用中のフィルターには `※` が付く（例: `AAA※`）
- タイトルに適用状態 `[ON]` / `[OFF]` を表示
- 複数フィルターの同時適用が可能（`<Tab>` で複数 ON にする）
- 適用中フィルターが0件になると自動で全メモ表示（OFF）になる

## フィルター適用中のメモ追加

- `<leader>ma`（追加/編集）・`<leader>ms`（候補リストから追加）の入力欄に、フィルター文字列＋スペースが事前入力された状態で始まる
- 複数フィルター適用中は先頭のフィルターが使われる

## グループ色（`<leader>mc`）

- カーソル配下のメモがフィルターグループに属する場合、グループ色として保存され、全ファイルの同グループメモに反映される
- どのフィルターにも属さないメモは従来どおり個別色変更となる
- 色の優先順位: フィルターグループ色 → メモ個別色 → デフォルト（`MemoHighlight`）

## セッション連携

- セッション保存時（`:Uss` / `usos` / Sessions 画面の `<C-o>`）にフィルター選択状態（適用中フィルター＋ON/OFF）をセッション名に紐付けて保存する
- `us` でのセッションロード時に自動で復旧する
- セッションのリネーム・削除にも紐付けが追従する

## 永続化

`~/.vim/memo_filters.json` に保存される。

```json
{
  "active": ["HOGE"],
  "enabled": true,
  "filters": [
    { "color": "#FFD700", "name": "HOGE" }
  ],
  "sessions": {
    "default": { "active": ["HOGE"], "enabled": true }
  }
}
```

| キー | 内容 |
|---|---|
| `filters` | フィルター定義一覧（名前とグループ色） |
| `active` | 適用中のフィルター名 |
| `enabled` | トグル状態（false なら全メモ表示） |
| `sessions` | セッション名ごとのフィルター選択状態 |
