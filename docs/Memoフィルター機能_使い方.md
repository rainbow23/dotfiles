# Memoフィルター機能 使い方

メモの先頭文字列（グループ名）で表示をフィルターする機能。
実装: `nvim/lua/rc/memo.lua`（セッション連携は `nvim/lua/rc/session.lua`）

## 概要

- メモの先頭文字列がフィルター文字列と前方一致するメモのみを表示する
- 例: フィルター `HOGE` を適用すると `HOGE AAA` `HOGE BBB` のメモだけが表示される
- フィルター名の直後が空白か文末のときだけ一致する（`AAA` は `AAA hoge` に一致し、`AAABB x` や `AAA!` には一致しない）
- 1 つのメモが属するフィルターは 1 つだけ。複数に一致する場合は名前が最も長いフィルターに属する（`NEW FILETER! x` は `NEW` ではなく `NEW FILETER!`）。表示・`<leader>mL`・グループ色はこの判定に従う
- 非表示メモも extmark 自体は残るため、フィルター中に行編集しても位置は正しく追従する

## キーマップ

| キー | 動作 |
|---|---|
| `<leader>mg` | フィルター決定。カーソル行にメモがあればそのテキストを初期値に編集（方式1）、なければ空入力から新規作成（方式2）。Enter で登録・適用。入力中は `<C-k>`/`<C-j>` で登録済みフィルターをポップアップから選べる |
| `<leader>mt` | 適用するフィルター（1 つだけ）と全体の ON 状態 / OFF 状態をポップアップで決める |
| `<leader>mo` | Telescope フィルター一覧を表示 |
| `<leader>mL` | 選択中（`※`）のフィルターに属するメモの一覧。OFF 状態でも選択中のフィルターで絞り込む |

## フィルター決定のポップアップ（`<leader>mg`）

`Filter:` の入力中に `<C-k>` を押すと、コマンドラインの直上に登録済みフィルターのポップアップが出る。

| 操作 | 動作 |
|---|---|
| `<C-k>` | 1 つ上（古い方）へ移動。初回は最下行（最近使ったフィルター）を選択。ポップアップ表示中は `<C-p>` でも可 |
| `<C-j>` | 1 つ下（新しい方）へ移動。最下行で止まる。ポップアップ表示中は `<C-n>` でも可 |
| `<CR>`（ポップアップ表示中） | 決定。選んだ名前を入力欄に決め、ポップアップは開いたまま（タイトルに `✔決定`） |
| `<Esc>`（ポップアップ表示中） | ポップアップを閉じる（`<CR>` で決定した内容は入力欄に残る） |
| `<CR>`（ポップアップなし） | 入力内容でフィルターを登録・適用 |
| 文字入力 | ポップアップを閉じて、そのまま編集を続ける |

- 並び順は最近使った順（古いものが上、最新が最下行）。フィルターを適用（`<leader>mg` で決定、`<leader>mt` で ON）した日時で更新される
- 選択中の行で入力欄の文字列も置き換わる

## メモ追加・編集時のフィルター選択（`<leader>ma`）

`Memo:` の入力中も `<C-k>` で同じフィルターポップアップが出る。選んだフィルター名が入力中の文言の先頭に付く。

例: `AA` のメモで `<leader>ma` → `<C-k>` で `filterA` を選ぶ → 入力欄が `filterA AA` になる → `<CR>` で決定 → `<Esc>` でポップアップを閉じる → `<CR>` で確定

| 操作 | 動作 |
|---|---|
| `<C-k>` / `<C-j>` | フィルターを選ぶ（操作は `<leader>mg` と同じ）。入力欄は「フィルター名 + 元の文言」に置き換わる |
| `<CR>`（ポップアップ表示中） | 選んだ内容を入力欄に決定する（ポップアップは開いたまま） |
| `<Esc>`（ポップアップ表示中） | ポップアップを閉じる。決定した内容は入力欄に残るので、`<CR>` でメモを確定 |
| 文字入力 | ポップアップを閉じて編集を続ける |

- 元の文言に登録済みフィルター名が付いている場合は付け替える（例: `HOGE BB` で `FUGA` を選ぶと `FUGA BB`）
- 新規メモでは「フィルター名 + 空白」が入るので、そのまま続けて入力できる

### メモ入力履歴（`<C-r>`）

`<leader>ma` / `<leader>ms` で確定したメモの文言は入力履歴として保存される（新しい順に最大 100 件、同じ文言は 1 つにまとめる。`~/.vim/memo_history.json`）。
`Memo:` の入力中に `<C-r>` を押すと、履歴のポップアップが出る。

| 操作 | 動作 |
|---|---|
| `<C-r>` | 履歴ポップアップを開く（最下行 = 最新を選択）。表示中にもう一度押すと 1 つ上（古い方）へ |
| `<C-k>` / `<C-p>` | 上（古い方）へ移動 |
| `<C-j>` / `<C-n>` | 下（新しい方）へ移動。最新で止まる |
| `<CR>` | ポップアップを閉じ、選んだ文言を入力欄に残す（カーソルは入力欄の末尾）。もう一度 `<CR>` でメモを確定 |
| 文字入力 | ポップアップを閉じて、選んだ文言を編集し続ける |
| `<Esc>` | ポップアップだけ閉じて、入力欄を開く前の文言に戻す（ポップアップが出ていなければ入力を取り消す）。フィルターのポップアップも同じ |

- フィルターのポップアップ（`<C-k>`）を表示中に `<C-r>` を押すと、履歴のポップアップに切り替わる
- 入力中の `<C-r>` は履歴用になるため、コマンドライン標準の「`<C-r>{レジスタ}` で貼り付け」は `Memo:` の入力中だけ使えない

### ポップアップからフィルターを作成する

フィルター選択ポップアップの最下行に `＋ フィルターを作成` がある（最新のフィルターから `<C-j>` で 1 つ下）。

```
╭─ 新規フィルター名  <CR>=作成 <Esc>=戻る ─╮
│ NEWF▏                                   │
╰─────────────────────────────────────────╯
╭─ Filters (新規)  … <CR>=作成 ───────────╮
│ ██ HOGE                                 │
│ ██ TODO                                 │
│ ＋ フィルターを作成   ← 選択中             │
╰─────────────────────────────────────────╯
Memo: AA
```

1. `＋ フィルターを作成` を選んで `<CR>` → さらに上に名前入力ポップアップが出る（入力モード）
2. 名前を入力して `<CR>` → フィルターを登録（適用はしない）し、フィルター選択ポップアップに戻る
3. 戻ったポップアップでは作成したフィルターが選択済みで、入力欄は `NEWF AA` になっている → `<CR>` で決定 → `<Esc>` で閉じて `<CR>` でメモを確定

- 名前入力で `<Esc>` を押すと作成せずにフィルター選択ポップアップに戻る
- 既にある名前を入力した場合は新規作成せず、そのフィルターを選択した状態で戻る
- フィルターが 1 件もないときは `<C-k>` で作成メニューだけのポップアップが出る

## フィルター切り替えのポップアップ（`<leader>mt`）

適用できるフィルターは 1 つだけ（排他的選択）。

```
╭─ Filter Toggle [ON状態]  <C-k>/<C-p>=上(古い) <C-j>/<C-n>=下(新しい) <CR>=決定 <Esc>=閉じる ─╮
│ ██ FUGA                                       │
│ ██ HOGE※                                      │
│ ██ TODO                                       │
│ ◉ 全体: ON状態   ← 起動直後はここ              │
╰───────────────────────────────────────────────╯
```

| 操作 | 動作 |
|---|---|
| `<C-k>` / `<C-p>` / `k` | 上へ移動 |
| `<C-j>` / `<C-n>` / `j` | 下へ移動 |
| `<CR>`（フィルター行） | そのフィルターだけを適用する（ほかのフィルターは外れる）。適用中のフィルターなら適用を外して OFF 状態にする。ポップアップは開いたまま |
| `<CR>`（全体の行） | ON 状態 / OFF 状態を切り替える（開いたまま）。フィルターを 1 度も選んでいないときは切り替えない |
| `<Esc>` / `q` | 何も変えずに閉じる |

- `※` は選択中のフィルター。OFF 状態でも選択は残るので、全体の行の `<CR>` で再び ON 状態にできる
- 並び順は `<leader>mg` のポップアップと同じ（最新が下）。開いている間は並びを固定する

## Telescope フィルター一覧（`<leader>mo`）

| 操作 | 動作 |
|---|---|
| `<Tab>` | カーソル行のフィルターだけを適用（ほかは外れる）。適用中のフィルターなら外す（トグル後カーソルは1行上へ移動） |
| `<CR>` | 閉じる（適用状態は `<Tab>` で反映済み） |
| `<C-d>` | フィルター定義を削除（メモ本体は変更しない） |

- 各フィルターは色アイコン `██` 付きで表示される（グループ色未設定はデフォルトのメモ色）
- 適用中のフィルターには `※` が付く（例: `AAA※`）
- タイトルに適用状態 `[ON]` / `[OFF]` を表示
- 適用できるフィルターは 1 つだけ
- 適用中フィルターが0件になると自動で全メモ表示（OFF）になる

## フィルター適用中のメモ追加

- `<leader>ma`（追加/編集）・`<leader>ms`（候補リストから追加）の入力欄に、フィルター文字列＋スペースが事前入力された状態で始まる
- 新規メモの確定時、文言がどのフィルターにも当てはまらなければ適用中のフィルター名を自動で先頭に付ける（事前入力を消した場合も、追加直後に非表示にならない）
- `<C-r>` で選んだ履歴にも、適用中のフィルター名を付けて入力欄に入れる
- `<leader>mf`（定型メモ）も「フィルター名 + 定型文」で追加する
- `<leader>ma` の `<C-k>` で選んだフィルターのままメモを確定すると、そのフィルターが適用状態（1 つだけ）になる。次の `<leader>ma` ではそのフィルター名が事前入力される

## グループ色（`<leader>mc`）

- カーソル配下のメモがフィルターグループに属する場合、グループ色として保存され、全ファイルの同グループメモに反映される
- どのフィルターにも属さないメモは従来どおり個別色変更となる
- 色の優先順位: フィルターグループ色 → メモ個別色 → デフォルト（`MemoHighlight`）

## セッション連携

- セッション保存時（`:Uss` / `usos` / Sessions 画面の `<C-o>`）にフィルター選択状態（適用中フィルター＋ON/OFF）をセッション名に紐付けて保存する
- `us` でのセッションロード時に自動で復旧する
- セッションのリネーム・削除にも紐付けが追従する

## 永続化

`~/.vim/memo_filters.json` に保存される。

```json
{
  "active": ["HOGE"],
  "enabled": true,
  "filters": [
    { "color": "#FFD700", "name": "HOGE" }
  ],
  "sessions": {
    "default": { "active": ["HOGE"], "enabled": true }
  }
}
```

| キー | 内容 |
|---|---|
| `filters` | フィルター定義一覧（名前とグループ色） |
| `active` | 適用中のフィルター名 |
| `enabled` | トグル状態（false なら全メモ表示） |
| `sessions` | セッション名ごとのフィルター選択状態 |
